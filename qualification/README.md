# Qualification records

`../QUALIFICATION_SUMMARY.md` is the authoritative release-level status for v1.0.0.

This directory preserves detailed staged-development evidence. Some older `GATE_*_STATUS.md` files are intentionally retained as historical candidate snapshots and may describe a gate as pending at the time that snapshot was written. Later closed-stage evidence and the release-level summary supersede those intermediate labels.

Long laptop-unfriendly studies that were deliberately deferred are listed in `POST_RELEASE_DEFERRED_QUALIFICATION.md`.
