# Candidate 1 runtime qualification

This directory adds **qualification-only** runtime drivers and cases.  It does
not alter the compile-passed Candidate 1 production C++.

## One-command suite

With OpenFOAM Foundation 14 sourced:

```bash
./qualification/candidate1Runtime/RunCandidate1RuntimeQualification 2>&1 | tee log.Candidate1.runtimeQualification
```

The suite is intentionally small/laptop-friendly.

## Automatic-unrefinement gate

```bash
./qualification/candidate1Runtime/RunPlanarAutoUnrefRuntimeGate 2>&1 | tee log.Candidate1.autoUnref
```

It compiles a small qualification-only mesh-update driver and checks:

- uniform slab: `1200 -> 4800 -> 1200 -> 4800 -> 1200`;
- localized slab: `1200 -> 2352 -> 1200 -> 2352 -> 1200`;
- annular wedge: `1600 -> 6400 -> 1600 -> 6400 -> 1600`;
- volume and two mapped scalar integral invariants at every topology change;
- strict `checkMesh` on every serial refined/coarsened state;
- a fixed-decomposition MPI2 reversible cycle;
- intentional refusal of restart while reversible split ancestry is active;
- safe restart from a fully coarsened state followed by re-refinement.

The localized slab reproduces the earlier qualification selection count of 384
base cells, so the first planar split gives `1200 + 3*384 = 2352` cells.

Runtime redistribution/load balancing is **not** exercised here because
Candidate 1 deliberately refuses `distribute()` while reversible ancestry is
active.  That is a documented Candidate 1 restriction, not an omitted test.

## Published OF8 H/H2 Soret gate

```bash
./qualification/candidate1Runtime/RunPublishedOF8SoretRuntimeGate 2>&1 | tee log.Candidate1.Soret
```

The transport probe constructs the real OF14 multicomponent thermo, momentum
transport, and `legacyMixtureAverageFourier` model and calls the public species
flux API `j(Yi)` directly.

The diagnostic composition is uniform (`Y_H=0.005`, `Y_H2=0.1`,
`Y_N2=0.895`) while `T` has an axial gradient.  All H thermal-diffusion
polynomials are zero and **only `H2-N2/ThermDiff_1 = 100` is nonzero**.  The
published-OF8 mode reads coefficients from the original `constant/thermoDiff`
layout.

For the exact published OF8 assignment:

```text
raw_H  = q     # H2 polynomial is accumulated into TDRatio_H
raw_H2 = 0     # TDRatio_H2 remains zero
sumRaw = q
```

After the legacy zero-net-mass-flux correction:

```text
j_H  = -(1-Y_H) q
j_H2 = Y_H2 q
```

so the runtime gate checks

```text
(1-Y_H) j_H2 + Y_H2 j_H = 0
```

face by face, independently infers the direct H2 contribution and requires it
to be zero, checks that the sum of **all 33 species fluxes** closes to zero,
and compares against a `legacyThermalDiffusionMode off` control where the
uniform-composition diffusive fluxes must be zero.

The coefficient value `100` is deliberately synthetic and exists only to make
the source-assignment behavior numerically unambiguous.  It is **not** a
physical or recommended H2-N2 Soret coefficient.

## Returned files

If the suite fails, the most useful return material is simply the complete
`qualification/candidate1Runtime/results/` and/or `resultsSoret/` directory,
or the top-level `log.Candidate1.runtimeQualification` generated by the command
above.
