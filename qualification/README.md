# Qualification records

`../QUALIFICATION_SUMMARY.md` is the authoritative release-level status for
OpenFOAM 14 v1.1.0.

This directory preserves detailed staged-development evidence from v1.0.0 and
the v1.1.0 automatic-unrefinement/Soret extension. Some older `GATE_*_STATUS.md`
files intentionally remain as historical snapshots and can describe a gate as
pending at the time that snapshot was written. The release-level summary and
later closure notes supersede those intermediate labels.

For the v1.1.0 additions see:

- `V1_1_AUTO_UNREF_SORET_QUALIFICATION.md`;
- `INTEGRATED_H2_LAPTOP_SMOKE.md`;
- `candidate1Runtime/` for the exact isolated runtime harnesses used to close
  the feature gates.

Long laptop-unfriendly studies that remain deliberately deferred are listed in
`POST_RELEASE_DEFERRED_QUALIFICATION.md`.
